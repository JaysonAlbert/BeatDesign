# UI Contract: 分层导航与素材板
本文件为批准的交互约定；实现及验证证据见 ../verification.md。参考截图见 [研究](../research.md)。

## 1. 信息架构

```text
Projects
├─ 独立项目（原卡片入口、原手动封面）
└─ 剧集卡片（集数/明确手动封面或占位）
   └─ 剧集总览：有序分集卡片 | 剧集共享素材
      └─ 第 02 集（现有 Project）
         ├─ 项目画布 / 未归场
         ├─ 场次 01 雨夜街口
         │  ├─ 制作画布 A → Shot 01 / Shot 02 / 支持素材
         │  └─ 制作画布 B（需要时显式新建）
         └─ 场次 02 室内 → 制作画布
```

“镜头组”是创作组织，“制作步骤”是依赖节点，“同批结果/历史 take”在步骤详情中比较。场次名称和顺序不驱动实际剪辑顺序。总览展示真实集/场/组/素材/clip 分项计数；不凭卡片总数生成镜头数量或完成百分比。无人工验收数据时显示“未记录审核”，不把任务成功视为通过。

## 2. AppShell 和路径

保留 56px 顶栏与 Studio/Canvas/Editor/Assets。项目标题旁放“剧集 / 第 02 集 / 场次”上下文入口；点开为可收起导航面板，<960px 使用抽屉，非强制固定侧栏。键盘能开关、上下选择、Enter进入，Esc返回入口，可见焦点；触控目标尽量44px。

拟议路由：
- /:locale/series/:seriesId 为轻量总览，/assets 可作为其共享素材板入口。
- /:locale/canvas/:projectId?sceneId=S&canvasId=C&focus=cardId
- 现有 Studio/Assets/Editor 的 projectId 路径保留；共用验证器接收 sceneId/canvasId，Assets 另有 scope/mediaType/elementKind/folderId/usage/q。
- seriesId 从 Project 的归属服务推导，不接受 URL 声称的关系；跨集点击使用目标 projectId，原 ID 不变。
- Scene 有多画布：未给 canvasId 进入该场有序首个活跃画布；尚无画布则空态“新建制作画布”，GET 不建数据。
- 不带参数的旧 Canvas URL 始终打开默认项目画布。记忆最近场次只能是明确的界面快捷入口，不能改变旧 URL/MCP 含义。
- sceneId 与 canvasId 不匹配：保留项目入口并显示范围失效说明，用户选择有效场；不静默打开另一场。
- focus 需服务查归属。旧位置已移动时显示去向并更新 URL；已删除或不存在给明确返回操作，不创建替代卡片。

四工作区链接使用统一 context builder；scope 不支持的筛选不继续传，但保留合法叙事范围。Editor 始终显示本集完整时间线：场次标签只筛选侧栏/高亮相关片段，不隐藏片段造成剪辑假象。Studio 显示本次素材归场目标，不改变模型输入默认值。

## 3. 场次切换和局部工作

1. 点击场次/画布前，检查当前文档保存状态；等待成功或提示冲突/保留草稿/明确放弃。
2. 新加载按 projectId+canvasId 缓存；卸载旧文档轮询/订阅，取消旧媒体请求，过期回包不覆盖新范围。
3. 仅读所选画布和轻量目录，缩略图懒载。每文档 undo 栈隔离；切换后绝不能把另一文档的 undo 应用过来。
4. 搜索定位临时展开组、突出相关依赖并允许查看旧 take；临时标记不写组 collapsed、camera、resultCardId 或 pin。关闭定位恢复原显示。
5. 组容器/组内整理/组间排列仍显式命令，可撤销；没有“切场即自动重排”。跨画布无连线，引用详情给“来自哪个场/共享版本”入口。
6. “转入其他场次画布”先展示依赖闭包、容量、受影响绑定与阻塞。可选择将完整依赖一起转移，确认后一次事务；失败留在原处。不是自动迁移按钮。

场次可选梗概和制作备注；不硬编码 6 秒一个镜头，不自动把100秒影片扩为大量静帧。10–15秒连续动作偏好属于制作约定，本功能不生成镜头或改变时长。

## 4. 素材板

顶部范围：本场次 / 本集 / 剧集共享（独立单片无共享入口）；场次范围无选中场时要求选择，不能显示“本场”却查全项目。

筛选为正交维度：
- 媒体：全部 / 图片 / 视频 / 音频。
- 参考类别：角色 / 场景 / 道具 / 声音 / 其他；未建 Element 的素材为其他，不自动认定母版。
- 目录：本集目录或共享范围适用的组织关系；首期共享库不复用来源集文件夹树，folder 筛选在共享范围隐藏。
- 用途：参考 / 候选 / 时间线采用 / 未归场，数据不足显示未知而不猜测。

卡片显示缩略图、名称、媒体类别、来源集/场、Element版本（若有）、消费者数与真实剪辑使用次数；相同 Asset 去重。“已加载100 / 总计2,000”与未知总数分开。搜索/筛选进入 URL，可刷新；竞态旧请求取消，不闪回上一集结果。

详情含：
- 精确 Asset 与来源、Element身份和固定版本；
- 同批结果选择器（1/N），历史 take 列表，二者分区标注；
- 本集/跨集消费者列表，点击正确工作区 locator；
- 真实时间线 clip 及源入出点，明确“不在时间线”；
- “用于本集”“绑定所选步骤”“发布共享参考”是不同动作；浏览不会授予 membership 或创建节点。

## 5. 版本审阅

共享 Element 详情显示当前推荐版与自己所用版，更新提示不会遮蔽旧图。新增版本后先显示差异和消费者，用户勾选目标（精确到步骤/槽）：
- 保留此版：记录已看过新推荐，继续固定旧版。
- 采用此版：显示选中数、影响集/画布、未改历史/剪辑说明及阻塞；执行一次有界原子命令。
- 超过批次上限：明确列出分批方案，每批独立审阅；不提供暗中后台全剧升级。
- revision/推荐版变化：显示“预览已过期”，保留选择，重新预览后才能执行。

共享版本缺文件显示不可用；不能自动回退到最新成功图或旧输入。归档后历史 pin 仍可查看，禁止新绑定。离开剧集先展示本地化影响，用户决定是否保留此集为独立作品；不静默丢引用。

## 6. 空态、错误与可访问性

空剧集引导“加入现有项目 / 新建空白分集”；空场引导创建空画布，均不复制/生成影片。项目画布入口常可达，避免拆场后找不到旧内容。目录/场次已归档可从“显示归档”恢复；真实删除单独流程。

长集名/场名截断配完整 tooltip，状态有文本；Esc/焦点恢复、Tab顺序、屏幕阅读器标签及中英文同义词均纳入验收。操作错误展示具体对象和下一步；不得仅用红点或控制台日志。

导航预览/浏览器验收与真实影片创作审阅分开。设计审批不等于对母版、封面或成片的视觉批准。
