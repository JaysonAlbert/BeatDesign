## 实现对照

| Higgsfield 所见 | BeatDesign 当前实现 |
|---|---|
| 固定项目侧栏与 Tools / Folders | Studio、Assets 共用可收起项目导航，减少重复的顶部模式切换；窄屏初始关闭、切页后关闭 |
| 全页 Project brief | 独立制作简报编辑页；通过现有 organization.apply 保存，切页先保存，冲突保留本地内容并展示服务端文本 |
| Elements 分类、搜索和卡片 | 全部、角色、场景、道具、声音分类，搜索与媒体卡片；点击才打开具体元素与版本编辑 |
| Folders 管理素材 | 嵌套目录、新建目录与目录筛选；素材页默认显示搜索和媒体类型，其他筛选按需展开 |
| 项目内 Canvas 与全屏入口 | 保留 BeatDesign 独立 Canvas 路由，增加返回项目；完整场次管理进入项目页面，画布菜单仅快速切换 |

## 明确保留或尚未对齐的差异

- Higgsfield 可嵌入项目 Canvas；本版仍是独立 Canvas 页面，并非像素级复制。
- 简报当前为最多 30,000 字符的纯文本；没有复制富文本工具栏和模板文档行为。
- Higgsfield 新建目录的描述和颜色已看到；BeatDesign 当前沿用名称和父目录的数据结构，未增加这两个字段。
- 保留 BeatDesign 本地模型、剪辑时间线、跨集共享与固定版本引用。声音分类属于本地制作需要；已有片段不会随素材当前版本自动改变。
- 不增加没有后端支持的 Chat、AI Director、Share、Publish 或账户计费按钮。不把入口相似说成服务能力一致。
- 默认没有静帧预演、动态试拍入口。条件图和首尾帧仍由模型能力决定；不改既有影片审阅与暂停记录。
- 元素缩略图从当前查询到的前 500 个项目素材解析，未加载的旧素材显示类型占位；版本数据仍保留。
