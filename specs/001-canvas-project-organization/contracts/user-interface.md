# UI Contract: 组织与镜头制作

2026-10-20；待审核交互约定，沿用 docs/DESIGN.md 和现有 AppShell。

## 项目总览

- 默认仍打开原 Canvas；旧项目没有组时不自动猜测分镜，不自动改布局。
- 用户选择节点建立命名组，选择用途（镜头、共享参考、声音、包装、时间线），预览后应用。
- 折叠入口展示名称、成员数、当前展示结果、运行/失败状态和实际采用计数。
- 当前展示、剪辑采用、人工审核三个状态分别标识；没有人工决定时显示未审核。
- 明确分组的八镜示例最多八个镜头入口和四个支持入口；真实卡片仍完整保存。
- 选中镜头后显示相关外部引用，连接合并为可检查的计数关系；不是可提交的模型引用。
- 显示隐藏但仍运行的任务状态，不能因折叠丢失进度或取消入口。

## 镜头下钻与历史

- 从总览选择镜头并展开，再选择主要构图/生成/采用片段，最多三次操作可达。
- 保留现有 Take 选择器，不把隐藏的 output 记录重新摊成全部独立盒子。
- 当前链/全部版本是可逆显示选择；失败记录可定位，不只显示成功输出。
- 折叠、移动、展开后成员坐标恢复；“解除分组”不会使用“删除成员”路径。
- 键盘可聚焦、选择、展开和解除；危险影响说明不依赖 hover。

## Assets 与 Elements

- 目录树置于 Assets 的可折叠区域，窄屏使用抽屉；保留全项目与未分类入口。
- 搜索明确标注“此目录”或“整个项目”，查询完整分页数据，不只筛当前加载的图片。
- 支持批量移动；重名/循环等问题在提交前指出。移除目录展示提升到父级的素材和子目录，
  文案明确不删除媒体，不能混同源 Asset 删除。
- 保存为参考时选名称、用途和具体版本；不制作新的模型结果或媒体副本。
- 参考选择器展示 Element 名称、绑定版本、实际素材与用途；生成输入顺序可核对。
- 当前版本变化后显示待复核，用户可“应用新版”或“保留旧版”；两者都不自动重跑或改剪辑。
- 被使用参考移除时列出可定位使用者，要求先解绑或替换。

## 模板

- 选中制作步骤后“保存为模板”，预览步骤、文字/配置、连接和待绑定槽。
- 保存的是流程白名单；源媒体转槽，不把素材身份、任务或时间线当作模板内容。
- 选择本地模板，预览插入位置、模型警告、必填槽，显式绑定当前项目素材。
- 允许插入缺槽的可编辑草稿，占位不伪装为 Asset；明确禁用生成并给出补齐入口。
- 新模板实例不随库模板改名或移除而变动；“另存模板”创建独立库记录。
- 不出现保存/实例化后自动运行开关；生成仍使用现有明确操作。

## 时间线采用

- Timeline 节点/镜头采用面板读取真实 usage，展示实际 Asset、take、轨道位置与源区间。
- 多份素材采用不压成一个“最新结果”；旧 take 仍采用时能单独定位。
- 不再要求添加 Final timeline media index 笔记来承载素材清单；旧笔记不自动删除。
- hidden/muted 不等于未引用，采用清单如实标识；字幕与媒体分开列出。

## 冲突与恢复

- MCP 或另一窗口改变 revision 后，未编辑面板刷新；正在编辑的表单保留输入并提示冲突。
- 本地未保存内容不能被轮询或自动合并静默丢弃。
- 收到拒绝后保留预览与输入；明确提示重新读取或处理冲突，不自动重发产生新对象。
- 节点删除、解除分组、移除目录、移除参考和删除源媒体使用不同操作名称与影响说明。
- 移动、折叠等 Canvas 操作沿用 undo/redo，并保留生成期间新增结果。

## 视觉与验收

复用近黑生产画布、既有中性面板与图连接语义；不新增永久应用侧边栏或独立工作空间。
新增内容有中文、英文及现有 locale fallback，44px 触控目标、键盘可达和可见焦点。
第一次验收使用合成示例；截图标明开发预览，不表示已上线或真实影片已被整理。
