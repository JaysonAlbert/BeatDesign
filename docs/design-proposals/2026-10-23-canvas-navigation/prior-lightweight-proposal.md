# 场次导航与画布组织重设计提案

日期：2026-10-23，北京时间。状态：**设计待用户评审，未修改产品源码，未部署**。

## 本轮修订：内容优先的轻量导航

按用户反馈更新：采用轻量导航，取消默认的“静帧预演 / 动态试拍”画布入口。目录展示场次与实际画布，示例每场仅展示一个“主画布”；新建场次不自动批量生成阶段画布。用户仍可按需创建并命名额外画布。

两个区域一起调整：场次目录用于定位内容；镜头组工具栏用于排列、折叠和移动；生成节点详情用于当前节点的参考、参数和结果。示例改为“场景参考 → 视频生成”，镜头说明留在同一组内。分镜图、首帧图片、图片生成是按需使用的内容或输入，不作为导航中的强制阶段。

本轮仅调整产品设计，不修改影片的人工审核契约，也不移动或删除已有画布。参数页展示交互结构，实际可用输入模式与参数须按所选模型能力呈现，不能假设每个模型都支持所有模式。

## 目标与范围

一起替换 `Episodes and scenes` 长模态框与 `Organize Canvas` 长表单。降低寻找场次、整理所选内容、绑定当前步骤参考的操作成本；保留现有项目、场次、画布、固定版本及转移预检语义。

本轮是产品设计研究，不是影片制作；示例使用截图中的场次名称，节点、数量、版本及影响数据均为示意，素材区域明确为占位。没有上传影片、创建竞品项目或运行模型。

## 推荐布局：轻量导航

- 保留现有 56px 顶栏与 Studio/Canvas/Editor/Assets，中文环境使用中文标签。
- 项目标题旁“场次”打开左上方 240px 可关闭目录，不再居中遮挡全部画布。
- 目录：项目画布 → 有序场次 → 场内画布；未归场画布折叠为单独一组。导航节点与画布文件有不同图标/缩进。
- 单场单画布可一击进入；多画布显式展开选择。展开箭头与进入动作分开，不因展开加载其他画布。
- 本轮原型每场展示一个主画布，不预置阶段分类。点击画布后目录收起，顶部保留完整上下文；长名字截断应有完整可访问名称与提示。
- 行内只保留名称、展开、一个“更多”入口。改名、添加画布、调整顺序、归档放到该对象菜单。
- 创建入口统一在目录底部“新建场次”；查看归档是底部低频入口。单独项目不显示空的“剧集总览”；已归属剧集时，标题菜单提供剧集总览和换集。
- 搜索匹配场次与画布名称，保留父级路径，显示无匹配空态。正式版本应让方向键/Enter可导航、Esc收起并归还焦点。

## 后续可选布局：固定目录

同一目录可固定在左边，适合连续剧频繁切场，保留同样的对象菜单与选择上下文。固定是用户选择，不给所有工作区强加持久侧栏。

推荐默认轻量版；固定版的取舍是多占约240px画布宽度。桌面宽度足够时可同时打开目录与节点详情；不足960px时优先保证画布，打开详情前收起目录。手机采用单一抽屉/详情页，不能把两条长面板叠在画布上。会话内小宽度预览为了可阅读将内容纵向排布，不是手机画布拖拽的实现验收。

## 组织面板拆解：每个功能只有明确归属

| 旧功能 | 新入口 | 展示条件／必要信息 |
|---|---|---|
| 分组名称、用途、选区预览、创建 | 多选工具栏“编组” → 小表单 | 至少选中一个可编组节点；预览成员，再确认。用途默认可推断但可改 |
| 整理、横排、竖排 | 选中组上方“排列”菜单 | 明确写“当前组”或“所选 N 组”，不静默退回全画布 |
| 展开并排列所有组 | 画布菜单“整理所有组…” | 画布有组时才出现；展示范围，支持撤销。零组时给创建引导，不显示大片禁用表单 |
| 组改名、用途、封面结果、成员更新 | 组“更多” → 组设置 | 显示当前对象；成员更新先列新增/移出范围 |
| 组折叠／展开 | 组标题或所选组工具栏 | 保留现有能力，清楚显示折叠状态 |
| 组定位、取消编组 | 组更多菜单 | 定位只改变视野；取消编组保留节点 |
| 全部版本、全部参考连线 | 画布右上“显示”小弹层 | 纯显示设置，默认遵从当前已保存值，不改变输入绑定或时间线 pin |
| 绑定共享参考 | 选中生成节点 → 节点详情“参考” | 只显示支持的槽/类型；打开选择器后选对象与固定版本，确认绑定 |
| 审阅共享版本 | 参考条“查看差异” → 共享素材详情 | 当前固定版仍显示；采用前查看目标消费者与差异，不自动跟随推荐版 |
| 移动到其他画布 | 多选/组工具栏“移动到…” | 先目标选择，再依赖闭包、容量、执行任务与冲突预检，最后确认 |

## 三条评审路径

1. **找到下一场**：点“场次” → 展开穿衣角 → 主画布。当前场/画布高亮，切换前等待保存；失败保留原画布和选择。
2. **整理当前组**：选组 → 排列 → 横排/竖排。只影响明确范围；点击空白取消选择后工具栏消失。全画布整理有单独入口。
3. **换一个角色参考**：点生成节点 → 参考 → 选择共享角色和固定版本 → 预览绑定。版本升级走差异和消费者审阅，不能用一个裸下拉悄悄替换所有镜头。

## 视觉规格

沿用 `docs/DESIGN.md`：Figtree+CJK、近黑画布、炭灰面板、细中性边框。橙色只用于确认创建/采用等主动作；冷蓝用于图选择与连线。目录行和工具栏不画成整排重边框大按钮。桌面行高32–36px、输入36px、面板间距12/16px；触屏目标至少44px。主文字14px，辅助12px；原型节点内部示意标签最小11px，正式核心信息保持12px以上。

目录默认240px、节点详情约280–320px（原型276px）。详情采用简短参考行和“添加”入口；没有合法选择时整体隐藏。面板主体可滚动，但固定头部和主要动作；不会把导航、参考、转移三种任务串成同一条长滚动区域。

## 异常、空态与数据保护

- 空项目：项目画布常可达，场次区域仅“新建场次”。空场次：新建画布按钮，不由GET自动创建。
- 无选择：隐藏局部工具栏；新增节点和“显示”保留。多选混合内容：不显示单节点参考表单。
- 只读／归档：可浏览，有明确状态；只禁用相关写操作并说明原因。
- 切场保存失败：不离开，展示重试/保留草稿；未保存内容不丢失。
- 目录搜索、切场与结果轮询仍遵从现有 projectId+canvasId 隔离与竞态保护。
- 转移预览过期／正在生成／容量不足：保留选择，显示具体阻塞，不重复提交状态不明的命令。
- 所有写操作仍复用现有 UI/MCP Command Kernel；不新建数据库、任务系统或共享素材服务。
- 原型支持基本Tab/Esc与小弹窗焦点约束；树型键盘导航、真实保存失败、服务端预检和手机拖拽留待实现验证。

## 待评审决策与实施顺序

当前只请用户判断：轻量目录是否顺手；选组工具栏与视频节点详情的分工是否清晰；视觉密度是否合适。默认阶段入口已按反馈取消。方案通过后再改正式组件。

实现建议分两步但整体验收：先替换场次导航并接回现有服务；再拆解组织面板和迁移所有入口。重点文件是 `src/components/app/series-navigation.tsx`、`src/components/beatcanvas/organization-panel.tsx`，共享参考和转移复用原模块，不以重画UI为理由改业务语义。

正式验收须覆盖：无选择/单节点/单组/多组，0/3/200场，多画布与未归场，长中文名称，中英文，保存失败与预览过期；1440/1024/窄窗口视觉检查；键盘导航；原有功能无丢失。测试通过与用户看图认可分别记录。
