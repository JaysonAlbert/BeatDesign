# Higgsfield 实测后的场次与 Canvas 重设计

日期：2026-10-23，北京时间。状态：用户已批准开发；正式组件已在隔离分支实现，主实例未部署。

本版取代先前的常驻节点详情方案。六种实际状态、10 张原始截图及操作边界见 [实测对照](../../references/higgsfield/2026-10-23-six-states/README.md)。此前轻量目录方案留在 [历史提案](prior-lightweight-proposal.md)，不作为当前布局依据。

## 两处一起改

- `Episodes and scenes`：改为左上当前场次标题打开的紧凑目录。默认关闭；一场一画布可直接进入，多画布时再展开。保留项目画布、未归场、场次更多菜单与新建入口。没有默认静帧预演、动态试拍入口，也不自动生成阶段画布。
- `Organize Canvas`：移除常驻长表单。组操作贴在组上方；提示词、模型、生成入口进入节点本身；完整设置按需浮在右上；参考选择器在输入端口附近打开；历史结果放在节点下方。

布局由选择状态决定，不再把管理、生成、素材与转移同时铺开。参考图、首帧图仍可按模型需求使用，不是必经制作阶段。本次设计不修改影片既有审阅记录或生产暂停状态。

## 六种状态的直接映射

| 状态 | Higgsfield 当日实测 | 更新后的 BeatDesign |
|---|---|---|
| 未选择 | 无展开属性栏；标题在左上；创建工具在底部；缩放在左下 | 同样默认完整画布，场次目录与设置都关闭 |
| 选中节点 | 蓝色选择框；提示词编辑器在卡片内；模型与运行同排；参数快捷入口 | 相同层级；节点内编辑，不默认打开右侧三标签详情 |
| 选中组 | 组上方浮动工具条；运行、编组、排列等随选择显示 | 主行保留运行组、取消编组、排列、下载、更多；低频业务动作入更多 |
| 生成设置 | 右上浮动卡；参考与提示词 → 模型 → 参数 → 生成 | 对齐位置和顺序；图片/视频与不同模型分别显示有效字段 |
| 参考选择 | 从输入端口打开来源菜单，再在附近选择素材 | 同样就近选取；来源使用本集素材、剧集共享、上传 |
| 查看结果 | 节点显示媒体；下方历史缩略图；就地展开结果图库 | 相同结果浏览结构；采用版本与时间线素材固定关系保留 |

全屏入口已经点击，但模板结果报访问权限提示，未核实全屏页具体布局。原型的大预览属于 BeatDesign 提案，不能称为 Higgsfield 的精确复刻。

## 生成设置的对齐范围

| 设置 | 对齐方式 | 不应假装存在的能力 |
|---|---|---|
| 参考与提示词 | 放设置卡顶部；与节点内编辑内容同步 | 不把所有模型都当作支持多参考、首尾帧或音频参考 |
| 模型 | 单独选择行；菜单可显示能力摘要 | 只列实时模型注册表中可用项，不复制 Higgsfield 型号或可用状态 |
| 时长 | 视频专属，紧随模型；模型支持连续范围时用滑杆，离散值用选择 | 原型 5–15 秒仅为交互示例，不代表某模型能力 |
| 分辨率/画幅 | 并排紧凑字段；单值只显示值 | 不照抄竞品分辨率枚举 |
| 批量 | 有明确支持时放基础设置下方 | 不默认添加竞品的 1/4 批量能力，不把入队数量等同模型 batch |
| 原生音频 | 仅模型支持并且可切换时显示 | 不给无音频能力模型添加假开关 |
| 高级设置 | 折叠，按模型提供 | 不填充未接通的 seed、负向提示等控件 |
| 生成 | 底部主按钮；费用/本地执行状态来自真实预检 | 不复制 Higgsfield 积分价格；生成与组运行复用现有任务和输入校验 |

## BeatDesign 必须保留的差异

1. **项目、剧集、场次与剪辑导航**：竞品本批没有提供可照搬的分集场次树。保留 BeatDesign 的内容层级与创作/画布/剪辑/素材切换，但不常驻占据画布。
2. **共享参考的固定版本**：选素材后显示实际固定版本；升级共享版本仍审阅影响。Canvas 可显示最新可用结果，手工 pin 优先；时间线明确绑定 Asset，不随浏览历史结果切换。
3. **跨画布移动和组管理**：保留依赖、容量、执行中任务和冲突预检、撤销，以及既有组折叠/用途。入口收进所选对象更多菜单；不得为视觉简化丢弃已有能力。
4. **本地/远端模型能力**：输入槽、参数、价格和排队信息以 BeatDesign 实际能力为准，原型不宣称模型执行已接通。
5. **品牌与产品边界**：保留 BeatDesign 配色；不因竞品出现 Chat、Share、AI Influencer 等入口就新增整套服务。竞品的颜色、锁定、删除、收藏、Create element 等按钮，需逐项核对既有对应能力；本次不把它们伪装为已实现功能。现有删除操作仍保留其正常入口与确认语义。

窄窗口的纵向重排是本提案的阅读适配，不声称复制 Higgsfield 手机端，也不是移动端画布拖拽验收。

## 旧组织功能的去向

| 既有功能 | 新位置 |
|---|---|
| 选区编组、组名称/用途/成员 | 多选工具条与组更多 → 组设置 |
| Tidy up / Row / Column | 选组工具条 → 排列；明确当前选择范围 |
| 展开并排列所有组 | 画布标题更多 → 整理所有组；保留撤销 |
| 折叠、定位、取消编组 | 组标题/工具条/更多 |
| 全版本与全部参考连线 | 画布标题更多 → 显示设置 |
| 共享参考绑定与审阅 | 节点参考入口 → 素材与固定版本；差异审阅进入共享素材详情 |
| 跨画布移动 | 所选节点/组更多 → 目标与影响预检 |
