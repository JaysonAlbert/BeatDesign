## 对 BeatDesign 的设计启示（推论）

组容器与间距只解决摆放；复杂项目还需要让用户按目的切换信息：
制作依赖看工作流，找素材看分类板，比较候选进入节点详情，检查最终采用看实际 Timeline。
共享参考按角色/场景/道具/声音管理，不必在每个镜头组里复制一套；多个候选优先在同一制作步骤内浏览。
明确区分镜头、生成步骤、单批结果与历史版本，不能拿节点数代替叙事镜头数。
以上是本项目建议，不是竞品的官方制作规范；本次未更改 BeatDesign 源码或真实影片。
