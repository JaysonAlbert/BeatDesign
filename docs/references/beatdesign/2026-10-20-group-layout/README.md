截图保留原始 PNG，无裁剪或修改；尺寸、SHA256 见 capture-index.json。
操作：打开合成示例 → 组织画布 → 展开并整理全部组 → 关闭面板 → 适配全部节点。
示例包含 140 张卡、八个镜头组和四个支持节点；蓝色图片为合成占位图，不是正式影片素材。
截图中的中间空行保留独立参考和时间线，组间排列避开这些固定对象。

同次 22 项浏览器测试还覆盖组内竖排、指定两组的组间排列、保存重载、组拖动及撤销，
并断言未参与组、卡片内容、历史、时间线不变且零生成/上传。
用户连接的 Chrome 另行验证了生产构建的 3050 预览，并应用同一“展开并整理全部组”操作；
连接截图接口超时，因此本目录明确使用完成回归中的 Chrome 截图，不冒充该连接的截屏。

此证据支持实现行为，不代表用户视觉验收、合入、部署或真实影片已整理。
